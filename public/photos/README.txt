# FOLDER FOTO MA'HAD ALY DARUL WAHYAIN

Silakan masukkan file foto Anda ke dalam folder ini (`/public/photos/`).
Anda juga dapat langsung menambahkan dan mengunggah foto melalui fitur "Kelola / Tambah Foto" di halaman Galeri pada website.

Contoh nama file yang dapat digunakan:
- halaqah-quran.jpg
- kajian-kitab.jpg
- asrama-mahasantri.jpg
- mualim-pengajar.jpg
- gedung-kampus.jpg
- masjid.jpg

Foto yang Anda tambahkan di folder ini dapat dipanggil langsung dari website menggunakan jalur: `/photos/nama-file.jpg`.
